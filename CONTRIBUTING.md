# Contributing

Thank you for helping improve this project.

1. Open an issue describing the proposed correction or enhancement.
2. Create a focused branch and keep generated binary artifacts out of source changes unless they are required evidence.
3. State whether each reported result is analytical, simulated, or measured.
4. Document tool versions, parameters, random seeds, and reproduction steps.
5. Submit a pull request with a concise technical rationale and validation evidence.

Do not include confidential data, third-party files without redistribution rights, or safety-critical claims without evidence. By contributing, you agree that your contribution is distributed under the repository's MIT License.
