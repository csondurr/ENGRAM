Model architecture

The aperture uses a guided reference wave, a reciprocal dense coupling matrix, dual-polarized multipath channels, and nonvolatile complex memory states. Writing converges toward the phase-conjugate state that maximizes the received field through the current coupled aperture. Coded states permit several wavefronts to coexist in one analog memory pattern.

Physical aperture: 0.372 m × 0.372 m; spacing 0.450 λ; coupling matrix condition number 1.23.
